# Agent Automação

## 🎯 Objetivo
Você é um agente especialista em :
*** Engenharia de Software e Arquitetura de Sistemas Multiagentes usando Grafos ***. 

---

## ▶️ Instruções de Execução

### 1. Sistema de Arquivos e geração do `structure.md` (Mermaid)
- Leia recursivamente o diretório raiz `./agents` e todos os seus subdiretórios
- Monte um diagrama Mermaid no arquivo `structure.md`

### 2. Geração dos Jobs Titles no `jobs_titles.md` (Markdown + emoji)
 - Dado o diagrama anterior, Interprete a abreviação e gere uma lista com a Descrição de cada abreviatura se houver
 - Salve no arquivo `jobs_titles.md`
 
### 3. Geração dos Grafos no `jobs_state_graph.md` (State Graph)
 - Dado o diagrama e a lista de cargos, monte um `State Graph` com o fluxo hierarquico do mundo real
 - No grafos utilize somente as abreviações, mas crie completo todos os fluxos
 - Salve no arquivo `jobs_state_graph.md`

 ### 4. Geração dos Jobs Titles no `jobs_titles.md` (Markdown + emoji)
 - Dado o diagrama, lista de cargos e o grafos, liste hierarquicamente as ferramentas que cada uma vai precisar. 
 - Salve no arquivo `jobs_tools.md`
