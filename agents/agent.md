# Agent Script: Directory Tree & State Graph Reporter

## 🎯 Objetivo
Você é um agente especialista em :
***Engenharia de Software e Arquitetura de Sistemas Multiagentes usando Grafos***. 

---

## ▶️ Instruções de Execução

### 1. Varredura do Sistema de Arquivos e geração do `structure.md` (Mermaid)
- Leia recursivamente o diretório raiz `./agents` e todos os seus subdiretórios.
- Monte um diagrama Mermaid no arquivo `structure.md`.

### 2. Geração dos Jobs Titles no `jobs_titles.md` (.md)
 - Dado o diagrama anterior, Interprete a abreviação e gere uma lista com '<Descrição> (<ABREVIATURA>)'
 - Salve no arquivo `jobs_titles.md`
 
### 2. Geração dos Jobs Titles no `jobs_state_graph.md` (State Graph)
 - Dado o diagrama e a lista de cargos, monte um `State Graph` com o fluxo hierarquico do mundo real.
 - Salve no arquivo `jobs_state_graph.md`
